# Morphemic Alignment — Output Meaning vs Operator Intent

## Definition
Morphemic alignment: the meaning carried by output morphemes/sentences must match operator intent in sense, scope, presupposition, and register.

## Checks
1. **Paraphrase-back**: restate intent; get confirm on ambiguous scope.
2. **Scope pins**: quantities, dates, parties, obligations explicit.
3. **Presupposition scan**: flag loaded premises.
4. **Register match**: formal where binding; plain where explanatory.
5. **Drift log**: record paraphrase → output → operator correction.

## Why separate from epistemic
A claim can be true yet mean the wrong thing (wrong party, wrong period). Both alignments required.

## Tests
Intent-paraphrase agreement rate; scope-error rate; correction cycles (TBD targets).
