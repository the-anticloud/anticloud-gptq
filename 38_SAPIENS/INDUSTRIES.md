# Industries — Per-Vertical Application

## Method
For each vertical: define verifiable unit of work, error cost, abstention policy.

## Verticals
- **Legal**: clause extraction + citation check; abstain without source; morphemic scope strict.
- **Medical admin**: coding/summarization only; no diagnosis claims; calibration logged (TBD thresholds).
- **Finance**: reconciliation with tool verification; no forward guarantees.
- **Manufacturing**: procedure QA with paraphrase-confirm before actuation.
- **Education**: tutor that abstains + cites; tracks calibration per student (TBD metric).
- **Government**: sovereign deployment; audit trail per decision.

## Metric
Cost per verified-correct task; abstention rate; calibration error (TBD targets).
